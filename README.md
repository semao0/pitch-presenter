## Зачем

**Текст перед глазами.** Крупно, с подсветкой ключевых слов и ремарками для себя. Правите файл —
текст обновляется прямо во время репетиции.

**Время под контролем.** Не просто секундомер: у каждого слайда свой лимит, а в шапке — запас или
отставание от плана. Без лимитов время делится по объёму текста.

**Зал видит только слайды.** Подключили проектор — окно показа само открывается на нём во весь экран.
Листать можно из любого окна, кликом или кликером.

PDF открывается сразу, PowerPoint, Keynote и ODP — через LibreOffice. Светлая и тёмная тема,
русский и английский интерфейс.

## Слежение за речью

Кнопка **«Следить за речью»** над заметками включает микрофон по умолчанию. Произнесённые
слова становятся приглушёнными, текущее место подчёркивается, длинный текст прокручивается.
При смене слайда слежение начинается с его текста. Ремарки `>` не нужно произносить.
Ошибки в окончаниях и пропущенные слова слежение прощает: слова сравниваются нечётко.

**Автолистание** (переключатель рядом с кнопкой или `L`, по умолчанию выключено): когда вы
дочитали текст слайда, через 1,2 с откроется следующий, `Esc` оставляет текущий. Срабатывает,
только если указатель шёл по тексту, а не прыгнул в конец, и слайд показан хотя бы 4 с.
Слайды без текста или из пары слов («Спасибо!») и последний слайд не листаются.

При первом включении скачиваются GigaAM-v3 и Silero VAD (около 275 МБ) с проверкой
SHA-256. Затем распознавание работает без интернета: аудио не сохраняется и не отправляется
на сервер. Модель держится в памяти, только пока слежение включено. На macOS нужно разрешить
доступ к микрофону.

Пока поддерживается только русская речь. Возможны пропуски при шуме, импровизации и английских
терминах; для длинного отступления лучше выключить слежение.

### Модель и почему она

| | |
|---|---|
| Модель | [GigaAM-v3](https://huggingface.co/ai-sage/GigaAM-v3) от SberDevices, вариант `e2e_ctc`: 220M параметров, текст с пунктуацией. MIT |
| Файл | GGUF Q8_0 из [handy-computer/gigaam-v3-e2e-ctc-gguf](https://huggingface.co/handy-computer/gigaam-v3-e2e-ctc-gguf), ревизия закреплена. WER на FLEURS-ru 5,53% против 5,50% у F32 |
| Движок | [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp) (ggml): Metal на Mac, CPU на Windows и Linux. Silero VAD оттуда же |

До 2.2 слежение работало на sherpa-onnx (int8, CPU). Замер на MacBook Air M2, 8 ГБ, на 29 с
русской речи:

| Окно звука | sherpa-onnx int8, CPU | transcribe.cpp Q8_0, Metal |
|---|---:|---:|
| 2 с | 119 мс | 30 мс |
| 3 с | 176 мс | 41 мс |
| 6 с | 338 мс | 66 мс |
| Память процесса | 278 МБ | 48 МБ |

Поэтому теперь слушаем последние 3 с и раз в 1,5 с — до 6 с. Первая загрузка модели на Mac
длится ~17 с: компилируются шейдеры Metal. Дальше это меньше секунды. Модель [GigaAM-Multilingual](https://huggingface.co/ai-sage/GigaAM-Multilingual)
в transcribe.cpp не поддерживается, а через PyTorch на русском она не точнее v3 и тяжелее в разы.

Авторы модели: Kutsakov et al., [GigaAM: Efficient Self-Supervised Learner for Speech
Recognition](https://arxiv.org/abs/2506.01192), InterSpeech 2025. Лицензии модели и библиотек — в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), этот файл входит в каждую сборку.

## Текст спикера

Положите `talk.toml` рядом с `talk.pdf` — он подхватится сам.

```toml
minutes = 5                 # длительность выступления

[[slide]]
n = 1
title = "Боль"
time = "0:30"               # лимит на слайд
text = '''
Происходит ли на площадке то, что **должно** быть по плану?

> пауза — ремарка для себя
'''
```

`**жирный**` · `*курсив*` · `==подсветка==` · `- списки` · `> ремарки` · `reserve = true` — слайд
можно пропустить. Полный пример — [example.toml](example.toml).

| | |
|---|---|
| `→` `Space` · клик | вперёд |

## Что остаётся на диске

Настройки, модель распознавания и кэш слайдов лежат в каталогах приложения
(`dev.semao0.PitchPresenter`). Недокачанные файлы и модель прежних версий удаляются при включении слежения.
Удалить всё на macOS:

```sh
rm -rf ~/Library/{Application\ Support,Caches,WebKit}/dev.semao0.PitchPresenter ~/Library/Preferences/dev.semao0.PitchPresenter.plist
```
