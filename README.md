# Pitch Presenter

Режим докладчика для PDF и PPTX: текущий и следующий слайд, текст спикера, общий таймер и лимит на
каждый слайд. Второе окно с одними слайдами шарится в созвон или выводится на проектор, окна
синхронизируются между собой.

## Возможности

- PDF напрямую, PPTX/PPT/ODP/Key — через LibreOffice
- текст спикера в TOML или Markdown, перечитывается на лету: правишь файл — текст обновляется
- таймер выступления и лимит на слайд; без лимита время считается по числу слов
- метка «резерв» для слайдов, которые можно пропустить
- форматирование: **жирный**, *курсив*, ==подсветка==, списки, ремарки для себя
- навигация с клавиатуры и мыши, чёрный экран, размер шрифта, переход по номеру слайда

## Установка

**macOS** — `.dmg` для Apple Silicon и Intel в [Releases](https://github.com/semao0/pitch-presenter/releases).

**Linux** (Debian/Ubuntu):

```bash
./build-deb.sh
sudo apt install ./dist/pitch-presenter_*_all.deb
```

**Без установки** — нужны Python 3.10+ и `pdftoppm` (`poppler-utils`):

```bash
python3 present.py deck.pdf notes.toml --minutes 8
```

## Текст спикера

Один блок `[[slide]]` на слайд, полный пример — [example.toml](example.toml):

```toml
title = "Объектив"
minutes = 8

[[slide]]
n = 1                 # номер слайда в PDF
title = "Боль"
time = "0:30"         # лимит: 30, "30s" или "0:30"
text = '''
Происходит ли сейчас на площадке то, что должно быть по плану?

> пауза — ремарка для себя, в хронометраж не входит
'''
```

То же в Markdown: `## 01 · Боль @0:30`, текст под заголовком. Перевести в TOML:
`python3 present.py --to-toml notes.md > notes.toml`.

## Клавиши

| Клавиша | Действие |
|---|---|
| `→` `Space` `Enter` `PageDown`, ЛКМ | следующий слайд |
| `←` `Backspace` `PageUp`, ПКМ | предыдущий слайд |
| цифры + `Enter` | перейти к слайду |
| `Home` / `End` | первый / последний слайд |
| `↑` `↓` | прокрутка текста |
| `+` / `-` | размер шрифта |
| `t` / `R` | таймер: старт-пауза / сброс |
| `b` | чёрный экран |
| `a` | открыть окно для показа |
| `?` | справка |

## Устройство

`present.py` рендерит слайды в PNG (PDFium или poppler, с кэшем в `~/.cache/pitch-presenter`) и
поднимает локальный HTTP-сервер. Окна докладчика и зрителей — страницы из `web/`, они
синхронизируются через long-poll. Нативное окно — GTK3 + WebKit на Linux (`app.py`) и pywebview на
macOS (`desktop.py`, собирается PyInstaller в GitHub Actions).
