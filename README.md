## Зачем

**Текст перед глазами.** Крупно, с подсветкой ключевых слов и ремарками для себя. Правите файл —
текст обновляется прямо во время репетиции.

**Время под контролем.** Не просто секундомер: у каждого слайда свой лимит, а в шапке — запас или
отставание от плана. Без лимитов время делится по объёму текста.

**Зал видит только слайды.** Подключили проектор — окно показа само открывается на нём во весь экран.
Листать можно из любого окна, кликом или кликером.

PDF открывается сразу, PowerPoint, Keynote и ODP — через LibreOffice. Светлая и тёмная тема,
русский и английский интерфейс.

## Слежение за речью

Кнопка **«Следить за речью»** над заметками включает микрофон по умолчанию. Произнесённые
слова становятся приглушёнными, текущее место подчёркивается, длинный текст прокручивается.
Слайды переключаются вручную; при смене слайда слежение начинается с его текста.
Ремарки `>` не нужно произносить. Кнопка микрофона останавливает слежение.

При первом включении скачиваются GigaAM v3 CTC и Silero VAD (около 230 МБ) с проверкой
SHA-256. Затем распознавание работает без интернета: аудио не сохраняется и не отправляется
на сервер. Модели хранятся в каталоге данных приложения, отдельно от установщика.
При закрытии презентации микрофон выключается. На macOS нужно разрешить доступ к микрофону.

Слежение обновляется примерно каждые 300 мс, если компьютер успевает распознавать речь.
Обычно обрабатываются последние 2 секунды звука; каждые 1,5 секунды и в конце фразы —
до 3 секунд для восстановления контекста. На медленном компьютере интервал автоматически
увеличивается. Интервал обновления не равен задержке подсветки: она также зависит от
скорости распознавания и появления нескольких совпадающих слов.

Пока поддерживается русская речь. Это экспериментальная функция: возможны задержки и
пропуски при шуме, импровизации, числах и английских терминах. Короткие фразы менее трёх
слов не двигают указатель. Прокрутка вручную остаётся доступна; для длинного отступления
лучше выключить слежение. Используется открытая исходная модель, а не закрытые веса Glas,
дообученные на англицизмах.

## Текст спикера

Положите `talk.toml` рядом с `talk.pdf` — он подхватится сам.

```toml
minutes = 5                 # длительность выступления

[[slide]]
n = 1
title = "Боль"
time = "0:30"               # лимит на слайд
text = '''
Происходит ли на площадке то, что **должно** быть по плану?

> пауза — ремарка для себя
'''
```

`**жирный**` · `*курсив*` · `==подсветка==` · `- списки` · `> ремарки` · `reserve = true` — слайд
можно пропустить. Полный пример — [example.toml](example.toml).

## Клавиши

| | |
|---|---|
| `→` `Space` · клик | вперёд |
| `←` · правый клик | назад |
| `12` `Enter` | к слайду 12 |
| `G` | все слайды |
| `B` | чёрный экран |
| `T` · `Shift R` | таймер: пауза · сброс |
| `+` `−` | размер текста |
| `A` | окно показа |
| `?` | все клавиши |
